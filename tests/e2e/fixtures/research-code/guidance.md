# Adapter quality

Use the current vendor specification, accounting for errata. Preserve identifiers literally, including leading zeros. Convert units exactly; truncation is not a valid conversion. Cite source filenames for the contract decisions. Keep each vendor's input rules separate while sharing the output contract.

## Make

Do not modify the supplied sources or this guidance. Own only the assigned artifacts and return concrete checks and gaps.

## Review

Independently derive expected results from the current sources. Cover a normal record, zero duration, fractional-unit conversion, preserved leading zeros and each rejection rule. Report blocking findings separately from suggestions. Review without changing the candidate.
