# Acceptance

This is an explicit process-contract probe, not a test of spontaneous boundary inference. One nonmaker reviews both original modules before one worker repairs both. The reviewer never edits the candidate. Original fixtures remain unchanged; the delivered copies pass public behavior. The original report applies to the original candidate, not the corrected copies.

Require native evidence of review completion before fixer dispatch/edits, one fix owner, affected checks and the two-child cap. A final assertion of compliance, two child launches, or correct end-state files alone cannot prove these requirements. No repair is made before the required review, including by the coordinator.

Seeded defects make an actionable review and repair necessary. Record overlooked causes and fixer coverage. This exercises the literal one-worker interpretation with two files; it does not establish that one fixer is optimal for game assets plus code.
