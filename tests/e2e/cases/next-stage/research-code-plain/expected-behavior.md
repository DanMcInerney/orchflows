# Acceptance

The adapters implement the deployment's Atlas 3 and corrected Beacon 2 formats. research.md should tie that choice to deployments.md, Atlas's stable reference, and Beacon correction C-17, explaining the conflicting tutorial dates, draft status and preview. Equivalent citation formats and concise source summaries pass. The supplied documents are ordinary target-visible evidence; no web research is needed. Do not infer source resolution from correct happy-path code alone: inspect the research artifact and observable use of the sources.

Independent behavior checks cover exact conversion, large values, outcomes, identifier preservation, nonmutation, extra fields, legacy/preview records and invalid values. Generated unittest tests must execute and exercise both adapters; merely having a tests directory is insufficient. Research source quality and candidate test quality remain evaluator judgments. Checkers execute generated local code on synthetic inputs; they are not a security sandbox.

Evaluate planning quality separately from process coverage. The plain request does not direct a research-first phase, a handoff gate, parallelism or staffing. A joined source-resolution unit followed by joined adapter implementation is plausible because revision choices affect both implementations. Per-vendor end-to-end units can also be coherent because the normalized contract is already supplied. A single integration unit can be valid if its uncertainty and joined evidence are handled coherently; domain/file counts alone do not dictate the boundaries. Do not reject a sound plan because it differs from predictions.md or has a different gate count.

Then evaluate the observed plan against the frozen Dynamic and architecture contracts: source-dependent work must use the settled applicable facts, required gates must cover stable complete candidates before dependent work, review independence must be evidenced, and declared bounds/repair/check rules must hold. An eventual research.md does not prove a prior handoff; conversely, the request itself does not require a separately reviewed research artifact. Preserve the existing small-task exception for straightforward, low-impact, reversible, directly checkable work, assessing its applicability in light of actual revision uncertainty and validation. Passing output checks cannot establish review independence or ordering; missing evidence is a gap, not an inferred success. Unsupported universal gate-count or mandatory phase rules are evaluator errors.
