# Atlas quickstart

Last edited 2026-04-12 for spelling and navigation. The worked example below targets schema 2, retired on 2026-03-01; this edit did not migrate its payload.

Send {"id":17,"elapsed_ms":1250,"ok":true}. id is numeric, elapsed_ms is an integer millisecond count, and ok is a boolean. Convert ok into a success/failure label. This remains useful for archived exports, but it is not a schema 3 example.
