# Beacon troubleshooting quickstart

Last edited 2026-04-14 to repair an internal link. These troubleshooting examples still describe the retired schema 1 export; the schema 2 correction has not been applied to this tutorial.

Schema 1 used key, elapsed and state. elapsed counted milliseconds and state was "ok" for success or "failed" for failure. Example: {"key":"0008","elapsed":1250,"state":"ok"}. A recent page edit does not change its schema version.
