# Local integration documentation snapshot

These are public task inputs for synthetic services, not live endpoints. They are the complete source set for this exercise. Snapshot date: 2026-04-15.

The export consumers in this deployment are pinned to Atlas schema 3 and Beacon schema 2. Schema numbers, not document modification dates, determine applicability. A preview schema is not enabled merely because it has a larger number. For a pinned schema, a published correction explicitly supersedes the corrected reference or example.

Available pages:

- atlas-reference.md: Atlas schema reference and a future preview.
- atlas-quickstart.md: an older tutorial with later editorial maintenance.
- beacon-reference.md: Beacon schema 2 reference as originally published.
- beacon-correction.md: correction applicable to Beacon schema 2.
- beacon-quickstart.md: older tutorial with later editorial maintenance.
