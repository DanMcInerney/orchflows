# Gate pilot predictions, 2026-09-20

Recorded before native execution of the revised instructions. This is a development pilot of one implementation, not a matched comparison, reliability estimate, or test of all 31 task families in [the study](gate-study.md). Preserve failed and incomplete attempts. Any fixture, adapter or policy intervention needs its own recorded reason and fresh run.

Core policy: coherent results and real dependencies determine units. Guidance informs those judgments; supporting guidance does not create a unit. Each substantive gate has one independent reviewer and, only for actionable findings, one worker with at most one repair pass followed by required checks. Planning does not create an authoring unit. Saving a reusable process invokes Build, whose authoring review follows completed trials.

For the small weekly plan in save-dynamic, direct checked execution is acceptable under the trivial-task exception; substantive uncertainty would justify a separate task gate. This flexibility must not waive Build's authoring trial or review. Maker count and exact prose are not scored. Missing rendered inspection is reported rather than inferred from HTML. Missing native evidence is an audit gap, not proof of compliance or misconduct.

Use installed Codex CLI with the user's configured model and reasoning effort, stage-local copies of complete runtime packages, native skill discovery and fresh native session IDs. Record actual settings, commands, package hashes, child histories, artifacts, objective checks, independent audit and gaps. Keep evaluator criteria out of task prompts. Audit evidence is sealed before assessment; native read-only enforcement needs a host probe.

The initial pilot consists of these eight cases, one attempt each, with at most two concurrent harness sessions. Native children and Build's inner trials are additional. Long authoring tasks have separate trial/reuse bounds. A probe or infrastructure correction does not count as a successful task attempt. Further repetitions are justified by failures or unresolved evidence, not by choosing a favorable result.
