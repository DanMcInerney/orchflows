# Now

Now is the read-only fleet view. It assigns each eligible run to exactly one ordered band: **Needs attention**, **Active now**, or collapsed **Recently completed**. Runs retain canonical identities, exact lifecycle counts, last meaningful activity, and repository or workspace metadata only when the closed projection supplies it. Client identity is never inferred.

Each compact path is a reversible projection of dependency depth. Brief, Plan, Work, Review, and Verify are presentation labels, not lifecycle law. Expanding a group reveals every represented ticket identity and its real internal dependency edges. Attention outranks running, ready, waiting, and complete; malformed or unreadable state remains explicitly unknown.

Pause live freezes visual replacement for inspection; it does not stop or mutate a run. Selection, expanded groups, inspector tab, filters, graph component identity, and the paused flag are local view context and survive incoming snapshots. Reduced motion removes nonessential animation, and forced colors retain state words, glyphs, and borders.

The view consumes only closed same-origin projections. It never displays or requests prompts, tool inputs or outputs, command output, file contents, transcript text, or subagent conversation content.
