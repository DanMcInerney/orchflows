# Data slicing

A question one executor can own end to end gets one direct root. Slice only
genuinely separable pipelines — by dataset, population, or sub-question — or
dependency-ordered stages: pinning before analysis, analysis before the
terminal reproduction.

Context carries each member's dataset identities and frozen choices. Every
lane materializes its own outputs from the shared pinned inputs. Terminal
reproduction reruns every recorded pipeline and reconciles the findings.
