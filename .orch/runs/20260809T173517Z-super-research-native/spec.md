- `transport_grammar`:
  - Direct data HTTP is GET/HEAD only. The closed OAuth control plane permits exactly two `application/x-www-form-urlencoded` refresh operations: Reddit `POST https://www.reddit.com/api/v1/access_token` with form exactly `grant_type=refresh_token&refresh_token=<binding-secret>` and descriptor-owned Basic client authentication; Google/YouTube `POST https://oauth2.googleapis.com/token` with fields exactly `grant_type=refresh_token`, `refresh_token`, `client_id`, and `client_secret` from the static binding, omitting `client_secret` only for a descriptor-admitted public-client binding. Each is one bounded counted `oauth_control` attempt with no retry, redirect, replay, caller body, or returned token persistence; response content type/shape is schema-admitted, bytes are counted, and tokens/errors are memory-only and redacted. Initial authorization, device, code, consent, and login flows are outside the package. X uses only a preprovisioned bearer and performs no token POST; every other POST is rejected.
  - `github_gh` permits no REST path and exactly three descriptor-hash-pinned literal read query documents named `DiscussionList|DiscussionComments|DiscussionReplies`. Their respective argv shapes are exactly `gh api graphql -f query=<DiscussionList-literal> -F owner=<validated> -F name=<validated> -F first=<bounded> [-F after=<validated-cursor>]`; `gh api graphql -f query=<DiscussionComments-literal> -F owner=<validated> -F name=<validated> -F first=<bounded> -F number=<positive-int> [-F after=<validated-cursor>]`; and `gh api graphql -f query=<DiscussionReplies-literal> -F owner=<validated> -F name=<validated> -F first=<bounded> -F comment_id=<node-id> [-F after=<validated-cursor>]`. Only caller-selected repository/discussion/comment/cursor and page-cap variables are admitted. Auth is solely the approved ambient `gh` identity, checked against the out-of-manifest expected-principal fingerprint in the same counted query. The one required `-f query=<literal-document>` and only the named `-F` variables are allowed; `--paginate`, method/host/header/input/jq/template/cache/raw-field/slurp, every other flag or `-f`, arbitrary option/query, `mutation`, `subscription`, and introspection are rejected. `gh` may internally POST its fixed GraphQL read, but exposes no HTTP primitive.
  - Direct HTTP disables ambient proxy, cookie, and netrc state. Redirects are manual and hard-capped; before every counted hop credentials are stripped, then origin/method/policy and every DNS A/AAAA plus connected peer IP are revalidated before any route-owned credential can be reattached. Zero writes means zero remote resource, content, or account mutation.
