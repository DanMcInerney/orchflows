including exact scaffold pins and actual technical probe readings. Its 1s and
120s fixtures establish technical endpoints, not endpoint creative quality.
The creative document describes desired motion; the render-video method owns

as production-cleared. No paid provider or social publication is implied.

budget explanation and proof instead of stretching the same cards.

## Supplying the outside document verifier

There is no global document-verifier executable supplied by this package.
The caller supplies a local command after fixing the review evidence. A doc
identity has the form `doc:<path>@sha256:<digest-of-the-document-bytes>`.
First inspect the independent review ticket: its artifacts must name that exact
doc identity, its ordered standards and digests must match the maker, and its
findings must support acceptance without outstanding blockers. Freeze the
review evidence as a local read-only snapshot with the ticket identity, reviewed
artifact line, pins and findings, recording its SHA256. A hash alone does not
make a review acceptable; this inspection establishes the semantic binding.

For a plain Markdown script, this concrete command can be the outside integrity
verifier, substituting the verified interpreter and the four fixed arguments:

    <verified-python> -c "import hashlib,pathlib,sys; pairs=((sys.argv[1],sys.argv[2]),(sys.argv[3],sys.argv[4])); sys.exit(0 if all(pathlib.Path(p).is_file() and hashlib.sha256(pathlib.Path(p).read_bytes()).hexdigest()==h for p,h in pairs) else 1)" <document-path> <document-sha256> <review-snapshot-path> <review-snapshot-sha256>

Pass its argument vector in the canonical command form accepted by frame-close;
PowerShell's call operator is not part of that vector. Run absent/corrupt controls
and then the actual fixed files, retaining nonzero/nonzero/zero readings. The
command checks both files' existence and exact bytes; independent judgment
supplies content quality. Changed document bytes require review of the new
revision, not merely a new expected hash. No review snapshot or unresolved
required findings means no accepted direction, even when the document exists.
