Establish [library context](../../references/library-context.md). An assignment covers a site, web scope, feed set or related sources with caller question, dates, bounds and output location.

Use `orchflows:orch-work` with collection guidance, [evidence contract](../../references/evidence.md) and available readers. Instruct workers to collect within bounds and return the handoff.

For caller gathering, return native handles and expected evidence locations immediately. Otherwise gather actual outcomes and return them.
