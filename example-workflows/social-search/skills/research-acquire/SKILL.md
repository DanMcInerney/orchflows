Use this optional method inside a [search-site](../search-site/SKILL.md) worker or another acquisition assignment when the bundled routes or deterministic acquisition guarantees are needed. It runs in the current context, launches no agents and judges no research conclusions. In the retained backend references, maker means this worker and workflow reviewer means the calling evidence assessor; social-search assigns that assessment to its one rank-research judge.

Read [the essential acquisition method](references/acquisition.md) to prepare and run a plan. Read only the chosen source's section in [route guidance](references/selection-routes.md), following an operation reference when needed. The executable validator owns routine plan shape, date and cap checks. Load the full [protocol](references/protocol.md) and [operating](references/operating.md) references only for manual manifests or direct runner APIs, which lack the plan command's checkpoint and global-budget guarantees.

Reuse the caller's context from [home and runtime](../../references/home-runtime.md); standalone use resolves it once there. Run with that home runtime interpreter; the retained backend requires only Python 3.9+ and its standard library. Resolve scripts from this skill directory and write acquisition output below the assigned output directory outside the package. Keep the same worker and scope through discovery, semantic selection and resumed depth reads; `selection_required` is unfinished acquisition. Read hydrated text before including it, and give the judge or other caller the packet, digest, receipts and declared gaps described in the method. For a site-search assignment, link those artifacts from the shared evidence result; the packet alone is not the worker's local ranking or a sufficient research conclusion.
