# HTML dossier criteria

Apply these criteria alongside the resolved core Research and Writing standards when the rank-research judge makes the dossier, and during any separately requested review.

Produce one HTML file that opens offline without a server or external assets. Inline styles and any necessary scripts, fonts or images; source hyperlinks may remain external, but viewing the document must not fetch them. Open with the answer, then ranked supporting evidence, qualifications and source details. For evidence-only output, open with the bounded evidence findings instead of a synthesized answer.

Use a readable layout in light and dark themes, with an explicit page background, shared color tokens and tabular numerals for comparable figures. Caption figures, tables and charts with what they show, their source and date. Keep the level of visual detail proportionate to the answer.

Link important claims to same-page source entries containing the source title, relevant date and exact original locator (the packet's `normalized_locator` when using the backend). Keep those entries useful offline with the relevant supporting evidence or excerpt, within applicable quotation limits. External links allow later inspection of originals. Preserve source figures, outcomes and price strings without invented precision. Community quotations keep their author and their own available count; missing counts remain explicitly unknown.

Make every typed loss, unresolved sub-question and material coverage limit visible, and show contradicting evidence without averaging it away. Distinguish archive observations from fresh platform reads and content dates from observation times.

The judge checks the actual rendered file and its supporting evidence: offline assets, legibility in both themes, captions, working internal citations, source fidelity, dates, losses and contradictions. Check that source entries support the claims linked to them and omit unused bibliography padding. Report any rendering capability that was unavailable rather than implying visual verification occurred. These are the author's checks; a separate independent review of the final file happens only when requested.
