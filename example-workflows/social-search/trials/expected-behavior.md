# Trial acceptance

Evaluate artifacts and agent events. Record candidate versions, tools, elapsed time, entrypoint invocation and author preparation or interventions; unexercised behavior remains a limit.

- The workflow works from an unrelated project using only the brief and declared dependencies. Distinguish installed-package testing from explicitly supplied candidate roots.
- Collection assignments preserve scope ownership. One independent assessor receives every collection outcome and returns its completed assessment with whole-result coverage, without new collection or coordinator rewriting. Independent collection assignments launch before gathering.
- Supplied evidence goes directly to review when it satisfies the scope. Otherwise, collection covers only unmet scope; review receives supplied and returned evidence and gaps.
- Guidance, the evidence contract and the access reference resolve at the package boundary and reach collectors. Verify parent and specialization contents in consumers' read results, including errors, rather than relying on receipts or exit status. Unfamiliar sites use general guidance; missing explicit selections block dependent work.
- Caller bounds survive delegation, including time for handoffs and review when the caller supplies a total deadline. Shared originals have one owner; inspect actual reads for avoidable overlap.
- Handoffs preserve inspected support, dates, rank reasons, useful engagement and coverage gaps. Missing work never becomes no-results evidence. Outputs stay outside packages.
- A one-source request still ends in an independent brief. Supplied evidence that covers the scope goes to review without new collection. YouTube speech claims have inspected caption or media support; missing captions remain a gap.
