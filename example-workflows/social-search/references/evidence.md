# Evidence handoff

Write one compact `results.md` per collection assignment. Review accepts equivalent saved evidence. Link support instead of copying acquisition logs.

Include question, scope, date meaning, bounds, observed usage and coverage gaps. Status describes collection, not claim truth: `complete` means fulfilled bounded assignment; `partial`, useful unfinished evidence; `blocked`, unusable access; `no_results`, completed search without matches.

Rank retained items by contribution to the question. Each includes:

- Stable ID, rank reason, original URL, author/publisher and canonical locator for shared underlying work.
- Inspected support: contextual excerpts, labeled paraphrases or saved content with precise locators. Name inspected content: abstract, full paper, post, comments or transcript. URLs, tool handles and search snippets alone are leads.
- Relevant publication, event and revision dates; distinguish reported dates from original-source verification. Label in-window evidence, older context and undated leads. Replies/revisions do not refresh publication.
- Available item-level engagement, metric meaning, access provider and observation time. Missing counts differ from zero. Sampled discussion retains participant identities, parent context and selection/coverage limits; counts are not sentiment.

Distinguish source origin, discovery and access providers; separate source claims from collector interpretation. Return handoff location and material gaps.
