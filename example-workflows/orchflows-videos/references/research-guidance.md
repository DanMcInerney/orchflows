Primary platform marketing guidance, not renderer evidence. Its preference for DIY aesthetics also contradicts any universal demand for cinematic polish. No universal optimal duration, shot quota or quantified benefit is inferred.
- [TikTok SMB playbook](https://ads.tiktok.com/business/library/Global_SMB_Creative_Playbook.pdf), publication date unavailable: connects hook to payoff and a specific next action. [Ad specifications](https://ads.tiktok.com/resources/help/article/tiktok-auction-in-feed-ads?lang=en-GB), retrieved today: safe zone depends on dimensions, caption length and additional formats; fixed universal margins are not justified.
- [Remotion animation](https://www.remotion.dev/docs/animating-properties), page updated September 8, 2026: frame-derived properties via useCurrentFrame, interpolation/clamping and spring simulation; warns non-frame-driven transitions can flicker. This supports deterministic implementation, not a requirement to bounce everything.
- [TransitionSeries](https://www.remotion.dev/docs/transitions/transitionseries), updated September 8, 2026: transitions overlap scenes and subtract overlap from total duration; overlays preserve sequence duration. Adjacent-scene timing constrains transition length. Apply against pinned runtime, since current docs include newer-version notes; no upgrade recommendation.
- [Fonts](https://www.remotion.dev/docs/fonts), updated September 8, 2026: load font resources and ensure readiness before rendering/measurement. [Captions](https://www.remotion.dev/docs/captions/), updated same day: supports importing, transcription, display, and burned-in or subtitle-file export. Capability is not proof of transcription accuracy.
- [Preview](https://www.remotion.dev/docs/preview), updated September 8, 2026: Studio previews compositions; template commands vary. Preview is an applied-method step, not evidence that the final encoded file is correct.

Confidence high for what these primary pages say, not for causal lift. TikTok is a distinct upstream from Remotion but addresses paid-platform creative and cannot be silently generalized to every short-film genre. Multiple Remotion pages are one technical owner, not independent convergence. Publication dates missing where declared; retrieval date does not invent them.
