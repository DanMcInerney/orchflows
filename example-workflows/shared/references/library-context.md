# Library context

Require Orchflows core 0.12.0+ and native independent review. Resolve core `docs/architecture.md` and `orch-review` through native skills, supplied roots or core's `resolve` CLI. Apply that architecture; consult core `docs/hosts.md` for host capabilities and isolation.

Use the caller's task guidance; this library supplies no domain criteria. A standalone invocation selects its task domains. Comparison returns evidence and preference without editing or adopting a candidate.
