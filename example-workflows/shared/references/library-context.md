# Library context

Require Orchflows core 0.11.0+ and native child delegation. Resolve core `docs/architecture.md`, `docs/hosts.md`, `orch-work`, `orch-review` and, for revision, `orch-review-revise-once` through native skills, supplied roots or core's `resolve` CLI. Apply core composition, execution and scoped guidance. Core hosts owns invocation and isolation.

Use the caller's task guidance; this library supplies no domain criteria. A standalone invocation selects its task domains.
