# Library context

Require Orchflows core 0.10.0+ and native child delegation. Resolve core `docs/architecture.md`, `docs/hosts.md`, `orch-work` and `orch-review` through native skills, supplied roots or core's `resolve` CLI. Apply core execution, guidance selection and standard review/repair where selected. Core hosts owns invocation and isolation.

Use the caller's task guidance; this library supplies no domain criteria. A standalone invocation selects its task domains.
