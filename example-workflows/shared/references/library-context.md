# Library context

Require Orchflows core 0.8.0+ and native child delegation. Resolve core and other named components through supported native skills, supplied package roots or core's `resolve` CLI. Core `docs/architecture.md` owns execution, bounds, settings and guidance selection; `docs/hosts.md` owns invocation and isolation. Do not bypass a rejected native invocation.

Run composition in the caller. Reuse the outer request, resolved guidance, artifact identities, scoped model/effort choices and remaining allowance. When invoked alone, select the caller's task domains and resolve guidance once; this library supplies process, not domain criteria. Explicitly missing domains or dependencies block their dependent work. Keep outputs in the caller's workspace.

Pass production instructions to makers and assessment instructions to reviewers, not this coordinating skill. Return compact handoffs and inspectable evidence. A component's default budget applies only when it has no inherited allowance. Preserve the caller's reserved later work and the local component allocation; do not spend the rest of the run merely because it is available.
