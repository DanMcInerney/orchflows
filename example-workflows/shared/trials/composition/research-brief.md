# Research brief

Inputs: source packet, question, research guidance, core package root and
an output directory. Output: an internal brief with source evidence and review.

Apply core composition. Draft a concise answer from the source using the research
guidance. Apply `orchflows:orch-review-revise-once` to the draft and source with that same
guidance; any necessary repair is limited to this brief. Return the delivered
brief, original review, checks and gaps. No external action is part of this work.
