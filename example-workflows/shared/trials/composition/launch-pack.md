# Launch planning pack

Inputs: source packet, research and campaign guidance, core and shared package roots,
and an output directory. This is an internal planning exercise.

Apply [research-brief](research-brief.md) to explain current commitments, the
optional module and expansion uncertainty. Keep its research guidance scoped to
that brief. Then create a separate short campaign concept from the supported
facts, adding campaign guidance only to that assignment. Return both outputs and
the brief's review limitations. Do not publish or contact anyone.
