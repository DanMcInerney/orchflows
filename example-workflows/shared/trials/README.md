# Behavioral trials

## Current acceptance

Current requests leave staffing to the orchestrator. The [builder journey](build-personal/request.md) discovers fitting components and creates and trials a fresh personal library with separate guidance. It also checks native entrypoint loading and reuses the guidance through a simpler process. [Expected behavior](build-personal/expected-behavior.md) is evaluator-only. Native registration, native execution and resolved-file composition are separate claims.

The comparison and office fixtures below remain reusable, with their obsolete staffing restrictions removed. Earlier observations are preserved as history; they do not validate the revised staffing policy.
