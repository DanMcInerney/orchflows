The workflow infers useful evaluation, calibrates it and checks the original. Each durable attempt start counts an attempt before proposal or production. Makers change isolated snapshots with applicable evolve and code guidance; ordinary production can run directly, continue a suitable maker or use `orch-work`, honoring scoped settings. Independent review confirms any measured gain. Behavioral regressions cannot win. Evidence identifies exact artifacts, both sides' measurements and evaluator version. The two-round bound ends the search with a resumable best, even if neither challenger wins; checkpoint writes and interruptions do not refund attempts.
