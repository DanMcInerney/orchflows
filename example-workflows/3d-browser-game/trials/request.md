# Trial request

Build a compact 3D salvage courier game for a desktop browser in the supplied empty workspace. Carrying valuable cargo should change movement enough that route choice matters. Provide a safe route and a risky shortcut, a readable setback and recovery, a clear delivery outcome and quick replay. Use Three.js and original Blender assets for the courier/cargo and a small environment kit. Give it one complete escalating mission rather than a large campaign. Keep the art coherent and the controls easy to learn.

Follow `3d-browser-game:3d-browser-game` from the supplied library root with the supplied core root. Leave source, exported assets, run/test commands and evidence in the project. Use the available browser and Blender tools. This is a bounded workflow trial; report limits rather than claiming broader production qualification.
