# Production outside probe

Document revision: `1.0.0` · Audience: package maintainers and the B1 integration reviewer · Voice: concise, factual, implementation-facing · Length budget: 450 words · Citation policy: claims point to the package helpers, dedicated tests, or the recorded `.orch-notes` fixture evidence.

`outside_probe.mjs` closes one joined game workspace from the package's installed location. A target supplies a frozen `outside_probe` config containing its build argv and output directory, the server readiness path, and an ordinary browser command sequence. Build and harness timeouts are `timeout_ms`; the server startup timeout is `startup_timeout_ms`. The package resolves its helpers from `import.meta.url`, invokes them with `process.execPath`, verifies the joined Git commit before and after each phase, and re-hashes every produced and captured byte.

The build adapter removes stale output before running the target build, rejects a failed build, tracked source changes, or a changed `HEAD`, and records the output inventory. The static server accepts only that inventory hash, reports its actual bound address and readiness response, confines requests to the output directory, and remains alive while the browser harness acts. The harness adapter uses the existing JSONL protocol with `server.external: true`, preserving a headed live-browser session, rendered canvas observations before and after ordinary input, screenshots, and a successful stop. The probe supervises and observes cleanup of both child processes on success, error, and timeout.

The seam accepts exactly one of `outside_probe.config` or a workspace-contained `outside_probe.config_path`; a path may carry `config_sha256`, which the probe re-hashes when it consumes the file. An indexed result may be retained inline as `outside_probe.result`, or beside the index through `result_path` and `result_sha256`. The returned observation is bound to `artifact_commit` and contains build output hashes, actual server bind/readiness, session identity/transcript hash, capture inventory, gate validation, and cleanup observations. Commands are sent over JSONL one at a time after the ready reply, so each reply is observed before the next command is delivered. It rejects self-assigned `pass` or `actual_play` labels; model-adaptive play remains the shared acceptance fixture's responsibility.

The disposable outside fixture recorded in `.orch-notes/outside-live` completed build, bind/readiness, headed browser input, PNG capture, and supervised close. The fixture was classified `scripted_input` and is protocol evidence rather than a completed sample-game claim. The dedicated outside test module includes fixed helper identity, stale/failed output, Git drift, server hash rejection, capability failure, and process timeout cases.
