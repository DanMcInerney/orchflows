# Expected behavior

- Reports requested calibrated pilot versus achieved prototype/draft and synthetic/unvalidated provenance. Variants remain in one source group; no invented unseen split or practical-performance claim.
- Tasks contain interacting scheduling dependencies and feasible reference outcomes; a service checks actual updates, global feasibility and preservation rather than a preferred assignment.
- Outcome credit rewards restored sessions, evidence-backed status and usable notices separately from preservation. An unresolved session can earn status credit without restoration credit; inert state is not progress.
- Full success and critical unauthorized changes are separate from weighted partial credit. A useful incomplete outcome can have high partial credit and still fail full success.
- Controls include a valid alternative, partial restoration, correct unresolved reporting, conflicting/unauthorized updates, empty output and unavailable judgment. Controls and bound checks accept valid results as well as rejecting invalid ones.
- Performs the public-only audit, real native target episode and one review with reset state and retained evidence. No evaluator material appears in the target prompt; local filesystem access is described honestly.
- Classifies target failures versus invalid tasks, grading defects and missing observation; one attempt does not calibrate difficulty or estimate run variation.
