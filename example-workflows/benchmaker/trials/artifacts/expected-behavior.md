# Expected behavior

- Inspects an example in its actual rendered modality before finalizing criteria and reads actual produced slides during the pilot.
- Separates factual/format constraints from anchored subjective readability/audience judgments. Alternative layouts can pass.
- Retains produced decks and visual evidence; parsed text or file existence alone does not establish artifact quality.
- Missing rendering/judge access leaves affected metrics provisional without silent string-match substitutions.
- Reports real native workflow execution, raw criterion evidence, elapsed time/cost and the two-execution limit.
