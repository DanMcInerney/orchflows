# Compact reconciliation benchmark

Use `benchmaker:benchmaker` to build and pilot a compact machinery benchmark for an assistant that reconciles invoice and credit records into a vendor summary. Use synthetic local CSV inputs with duplicate record IDs, missing references and credits. Require a usable summary, a discrepancy report and preservation of source rows; accept equivalent valid output formats. Keep numeric grading deterministic where possible.

This is a prototype of the benchmark machinery, not a substantial-work or population-performance claim. Use a named native representative agent as the target, real public-input executions and local output files. Keep the pilot to two target measurements and five minutes per measurement. Save the full package, controls, observations and unresolved validity gaps in the supplied workspace. No external financial operation or message is authorized.
