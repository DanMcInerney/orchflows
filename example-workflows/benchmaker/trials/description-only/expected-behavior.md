# Expected behavior

- **A self-contained draft.** The package has public tasks, environment fixtures, reference solutions, verifiers, labeled outcomes, profiles, a documented adapter boundary and a rejection log. There is no unnecessary question about the unavailable target.
- **Tasks that need reasoning.** Tasks require distinct conflict and change reasoning. Valid alternative schedules pass, and conflicts or invalid changes fail. Empty explanations cannot pass infeasible tasks, and no task is satisfied by its initial state.
- **Limits honored.** At most four labeled outcomes run per task, with a two-task blind audit, one adversary pass and zero candidate, representative or calibration launches. The auditor, adversary and review children are authoring overhead, recorded separately.
- **Draft stage.** The achieved stage is draft. Calibration and measurement are named as missing, with the launches needed to complete them. No mock score is called agent performance, and there is no invented held-out split.
- **Runnable commands.** Smoke, quick and full membership and estimates are stated. Target commands either invoke a configured real target or fail clearly when none exists. Offline checks remain runnable.
- **Honest delivery.** Evidence paths, actual checks, review and any repairs are reported. Generated output stays outside the library.
