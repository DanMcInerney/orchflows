# Request

Build a small benchmark for the supplied local support/planning agent. It changes reservations under a policy; some requests have several valid solutions and some must be declined with an explanation. Check unrelated reservations remain intact. Use six development cases, at most three native agent executions, concurrency two, no paid services and a five-minute pilot limit. Use resettable local state and keep all output in this workspace.

Trial setup: supply the actual agent invocation, public policy, a small initial reservation fixture and tool/reset interfaces. Include capacity conflicts, an allowed alternative and an infeasible request. Do not supply evaluator answers to the target.
