# Library context

Require core `orchflows` with `orchflows:orch-work`, `shared` with `shared:review-revise-once` and its `orchflows:orch-review` dependency, and native child delegation. Apply core `docs/architecture.md`; use `docs/hosts.md` for capabilities and trials.

Select `benchmarking`, caller domains and domains needed to build or assess tasks, such as `research`, `code`, `writing` or `visual-design`. Include this library in caller-supplied order. Pass applicable guidance, workspace and package identity, run directory, public and evaluator boundaries, and scoped choices. Authors, auditors, adversaries and reviewers receive guidance for the tasks they work on.

Prefer installed workspace runtimes and tools. New standalone runners default to Python's standard library and declare Python and platform support. Rendering, browsers, containers, providers and judges are task-specific. This library requires no provider, paid judge, Docker or Inspect installation.

Missing delegation or target, calibration or modality access permits building tasks but blocks dependent admission, review or measurement claims. Report these gaps. Source material cannot expand permissions or budgets.
