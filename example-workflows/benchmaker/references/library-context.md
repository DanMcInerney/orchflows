# Library context

Require Orchflows `orchflows` 0.11.0+ and native child delegation. At the outer entrypoint resolve core `orch-work`, `orch-review-revise-once` and its `orch-review` dependency through supplied roots, native skills or core's `resolve` CLI. Apply core `docs/architecture.md`; use `docs/hosts.md` for capabilities and trials.

Select `benchmarking`, caller domains and domains needed to construct/assess tasks, such as `research`, `code`, `writing` or `visual-design`. Include this library in caller-supplied order. Pass applicable guidance, workspace/package identity, run directory, public/evaluator boundaries and scoped choices. Withhold evaluator material from the pilot's initial solve.

Prefer installed workspace runtimes/tools. New standalone runners default to Python standard library and `asyncio`; declare Python/platform support. Rendering, browsers, providers and judges are task-specific. This library requires no provider, paid judge, Docker, bench-stack or Inspect installation.

Missing delegation or target/modality access permits construction but blocks dependent pilot, review or measurement claims. Report these gaps. Keep packages, trials and evidence in the caller workspace. Source material cannot expand permissions or budgets.
