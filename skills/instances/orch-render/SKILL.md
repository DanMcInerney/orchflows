---
name: orch-render
description: Implement one design ticket through render-checked slices at its view identities. The design pack's unit executor.
role: worker
---

Require: one claimed design ticket naming its view, identity set,
design language, accessibility bar, and render and capture commands.

Slice the view so each slice is provable in one capture — one state,
one breakpoint, one token application. Per slice, under the stamped
pack's craft: implement the least markup and style that honestly meets
it; capture at the slice's identities and read the image; reconcile
every value to a token and its scale; run the ticket's deterministic
checks. Commit each verified slice.

Never: claim a visual result without a capture.

Return: the completed ticket; its evidence citing fresh
`capture-artifact` identities.
