---
name: orch-compare
description: Compare alternative approaches through separate delegated candidates and independent review against shared criteria.
---

Use [orch-record-run](../orch-record-run/SKILL.md) for one outer `orchflows-light:orch-compare` run when a configured home is available. Reuse a caller's run/output context across composition and workers; finalize only a run owned here with the actual outcome. If history setup is absent, state the gap and continue the requested work.

Set the decision criteria and a comparable scope for the requested alternatives. Load [orch-work](../orch-work/SKILL.md) for each candidate, passing the same relevant standards; run independent assignments concurrently when the host permits. Keep their work separate and use neutral labels when author identity would bias comparison.

Load [orch-review](../orch-review/SKILL.md) to compare the actual candidates against those criteria and standards. Give the reviewer every candidate it needs, with repository candidates available in separate worktrees at their actual revisions. Keep missing results and unequal evidence visible.

Explain the recommendation and its tradeoffs. If the request includes a combined deliverable, use orch-work to join the chosen contributions and orch-review to inspect that joined result. Comparing options alone does not authorize implementing or publishing the winner.
