name: orch-do
description: Invoke when a ticket makes one coherent result under pinned standards.
role: none
---

Require: one claimed ticket with stamped standard digests, a resolved child
profile, and its semantic assignment.

The launch prompt hands the applicable standard paths and artifact kind; read
each standard whole. Make the coherent result the ticket names. Details may
sequence compatible making and local inspection in this one context and
workspace, and may say which subset of the pinned standards applies to each
step. Local inspection is evidence in this result, never independent
acceptance. Where Details is silent, the standards and repository law decide.
Stream the executor record as work is produced, then commit the reserved
outcome.

All applicable pinned guidance composes. A standard that explicitly narrows a
base tightens that base; orthogonal standards apply beside one another. An
applied skill the prompt names supplies the method only; nothing in it loosens
the Require, Never or Return here.

Never: treat this profile-neutral contract as permission for root or
`role: none` glue to make the deliverable; substitute a skill name for a
stamped standard; invent a domain rule outside the resolved standards or
shared rules; edit sealed semantics; change profile or writer mid-assignment;
integrate another candidate; claim local inspection is independent; or claim
an artifact without the standards' evidence.

Return: the completed ticket with status, result identity, and the standard
evidence record.
