Name the recurring request and useful result. Apply [architecture](../../docs/architecture.md) with `orchflows` and `writing` guidance. Author directly when settings permit or use [orch-work](../orch-work/SKILL.md).

Save the process, inputs, outputs and stopping conditions. Keep task details in the prompt and methods and taste in guidance. Discover relevant installed components; name them and supply their inputs without restating their contracts. Prefer a plain primitive assignment when a component needs substantial adaptation. Keep library context to dependencies, guidance routing and requested saved settings, referencing core rules. Verify [invocation policy](../../docs/hosts.md#invocation-policy).

Before review, [trial the behavior](../../docs/hosts.md#workflow-trials) on ordinary inputs in an unrelated workspace. Record preparation, interventions and gaps. Repair observed failures and rerun affected behavior as needed. Improvement claims require matched old/new trials.

Apply [standard review and repair](../../docs/architecture.md#standard-review-and-repair) to the candidate and trial evidence. Repeat affected trials when repairs require it. Return the artifact, evidence and gaps; verify native registration before claiming availability by name.
