---
name: compare-approaches
description: Compare alternative approaches through separate delegated candidates and independent review against shared criteria.
---

Set the decision criteria and a comparable scope for the requested alternatives. Load [delegate-work](../delegate-work/SKILL.md) for each candidate, passing the same relevant standards; run independent assignments concurrently when the host permits. Keep their work separate and use neutral labels when author identity would bias comparison.

Load [delegate-review](../delegate-review/SKILL.md) to compare the actual candidates against those criteria and standards. Give the reviewer every candidate it needs, with repository candidates available in separate worktrees at their actual revisions. Keep missing results and unequal evidence visible.

Explain the recommendation and its tradeoffs. If the request includes a combined deliverable, use delegate-work to join the chosen contributions and delegate-review to inspect that joined result. Comparing options alone does not authorize implementing or publishing the winner.
