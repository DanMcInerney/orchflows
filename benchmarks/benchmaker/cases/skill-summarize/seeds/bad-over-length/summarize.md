---
name: cache-rollout-digest
outcome: one cited digest of the source set, inside the declared bounds
---

```constraints
max_words: 400
citation_ids: closed
citation_coverage: every-sentence
```

Read every source in `evidence/sources.md`. Write one digest of the set.

Be thorough. Give each source its own treatment: state what it measured,
the figures it carries, and how it relates to the sources around it. A
reader who has not seen the set should be able to reconstruct it from
the digest alone, so restating a source in full is a feature, not
padding.

Cite with `[S<n>]` naming a heading that appears in `sources.md`; the
set is closed. Every sentence carries at least one citation.

Cover the rollout outcome and the incident.
