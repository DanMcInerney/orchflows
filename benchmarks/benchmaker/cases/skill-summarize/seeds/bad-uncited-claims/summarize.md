```constraints
max_words: 120
citation_ids: closed
citation_coverage: where-helpful
```

Read every source in `evidence/sources.md`. Write one digest of the set.

Cite with `[S<n>]` naming a heading that appears in `sources.md`; the set
is closed, so never reach for an id that is not in the file.

Cite where it helps the reader. Figures, dates, and percentages earn a
citation. Connective sentences that carry the reader between the cited
ones read better without the clutter, so leave those clean.

Stay within the word bound. Counting excludes heading lines and citation
tokens.

Cover the rollout outcome and the incident.
