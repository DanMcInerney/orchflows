# Evaluation design — fixed candidate set ranking

evidence-source: case-evidence:criteria.md
evidence-source: case-evidence:candidates directory

Boundary: the observable outcome is the ranking artifact — EXCLUDED
lines then RANK lines — produced by required verification followed by
scored aggregation over the fixed pool. Out of scope: candidate
regeneration, candidate execution, any criterion not in the
eligibility spec.

Flow direction: this design consumes only the case evidence named
above; the ranking is downstream output, never design evidence.
