# bad-offset

The package's reference model drops the first stream element before
sampling, so every expected trace — including the pinned trials of
the anchored case, which were regenerated to stay internally
consistent — is computed from the stream shifted by one element. The
package is self-consistent and schema-valid; it is simply wrong about
the target: the conforming reference implementation fails its cases,
and the anchored case no longer pins the exhibited sample. The
off-by-one stream-offset locus is a fresh-locus menu item for the
boundary-shift census name; the predecessor family never burned a
stream-offset locus.
