# bad-vacuous (inert)

The intended behavior is absent: the transcript oracle returns no
problems for any input, so the package-level aggregate gate accepts
an empty run — and every unlawful transcript besides. All three laws
(stage order, per-edge gates, frozen joins) are unenforced. This is
the case's inert variant; any probe that observes enforcement at all
fails it.

Locus freshness (burned-name argument, per the design): the
predecessor family burned `oracle-vacuity` at composition-target's
status/done-check oracle locus — its deviation line reads
`oracle-vacuity` at that case's workflow-status check. This seed's
vacuity sits at the successor package's package-level aggregate gate,
a locus the predecessor set never seeded; Q-BURN verifies the
distinctness against the predecessor's defect lines.
