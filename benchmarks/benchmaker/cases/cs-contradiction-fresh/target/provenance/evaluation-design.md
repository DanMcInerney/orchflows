# Evaluation design excerpt — dateparse benchmark

Frozen before construction; candidate-blind.

- Outcome: the canonical rendering (or rejection) the parser emits for
  one input under one mode.
- Contested-point law: where the two manual editions disagree, a point
  is cased only when a settlement artifact resolves it, and that case's
  provenance cites the settlement by identity; an unresolved point is
  registered in the disagreement register with citations to both
  editions and no case asserts either side of it.
- Selection rationale: agreed behaviors are cased from both editions;
  the settled strict-mode point is cased across its range including
  the edge year; the open point is registered, not cased.
